# JavaScript, with useful guarantees

TypeScript adds a static type system to JavaScript. It helps catch mistakes while you edit, before the code reaches a browser or server.

![The TypeScript shield](../assets/typescript-mark.svg)

<Image
  src='../assets/typescript-mark.svg'
  alt='A blue TypeScript shield marked TS'
/>

You can adopt it gradually: TypeScript compiles to ordinary JavaScript and works with the JavaScript ecosystem.

<Callout type='tip'>
  Start with the parts of your application where clear data shapes are most
  useful.
</Callout>

<Example title='A typed value'>

```ts
const learnerName: string = 'Ada';
```

</Example>

<Steps>
  <Step title='Describe a value'>
    Choose a type that matches the data, such as `string` for text.
  </Step>
  <Step title='Use the value'>
    Let the editor check that the value is used consistently.
  </Step>
</Steps>
