# JavaScript, with useful guarantees

TypeScript adds a static type system to JavaScript. It helps catch mistakes while you edit, before the code reaches a browser or server.

<Image
  src='../assets/typescript-mark.svg'
  alt='A blue TypeScript shield marked TS'
/>

You can adopt it gradually: TypeScript compiles to ordinary JavaScript and works with the JavaScript ecosystem.

## Start with useful data shapes

Start with the parts of your application where clear data shapes are most useful.

```ts
const learnerName: string = 'Ada';
```

## Put types to work

1. Choose a type that matches the data, such as `string` for text.
2. Let the editor check that the value is used consistently.
