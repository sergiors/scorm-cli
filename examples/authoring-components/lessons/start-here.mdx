# A guided tour of course components

This course introduces the small set of authoring components that shapes a SCORM course: presentation containers, reusable content blocks, media, and knowledge checks. Each example is MDX, so familiar Markdown works alongside the components.

<Callout variant="info" title="Two layers of authoring">
  The course entry file chooses one presentation. Its pages contain flow content such as text,
  images, videos, callouts, accordions, and questionnaires. Nested structures have their own
  stricter child rules.
</Callout>

## Follow the tour

The root `<Scroll>` presents these lessons continuously in the order declared by the course entry file. Optionally, a `<Path>` adds separate in-content navigation alongside that root presentation: its `<Page ref="…" />` children point to pages declared by `<Scroll>`. After setting up the project, continue through the component tour in this order.

Start by comparing the three presentation containers. Then explore content composition, images, video, and finally interactive assessment.
