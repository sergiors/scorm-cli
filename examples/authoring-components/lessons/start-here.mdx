# From authored content to a course

scorm-cli turns course content written in MDX into a learner-ready SCORM package. It parses and validates the authored content, renders it into a player, then packages that player for a learning management system. SCORM 1.2 is the default package format.

Use `scorm-cli preview` to run the player locally with a mock LMS, so you can review the course without connecting to a real learning management system.

## Follow the course

First install and run scorm-cli. Then build up your authoring skills in order: choose a presentation, compose lesson content, add images and video, and finish with an assessment.
