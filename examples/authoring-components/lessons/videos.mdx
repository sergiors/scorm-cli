# Add video with context

`<Video>` embeds one supported hosted video and must use an individual YouTube or Vimeo URL. The provider is inferred from the URL in `src`; you do not need to specify it separately. Optional attributes are `title` and `poster`.

Local video files, direct media URLs, playlists, and unrelated hosts are not supported by this component.

<Callout variant="info" title="Make video usable">
  Provide a descriptive video title. If a local poster path is supplied, it must also resolve to an
  asset in the package.
</Callout>
