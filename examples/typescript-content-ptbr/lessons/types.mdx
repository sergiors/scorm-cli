# Descreva seus dados

Use tipos primitivos como `string` e `number` e depois combine-os para modelar os valores que sua aplicação usa.

```ts
type Learner = {
  name: string
  completedLessons: number
}
```

Um tipo de objeto documenta os campos esperados e permite que seu editor ofereça sugestões precisas.
