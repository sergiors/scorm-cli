# JavaScript, mas com garantias úteis

O TypeScript adiciona um sistema de tipos estáticos ao JavaScript. Ele ajuda a encontrar erros enquanto você edita, antes que o código chegue a um navegador ou servidor.

<Image
  src="../assets/typescript-mark.svg"
  alt="Um escudo azul do TypeScript marcado com TS"
  caption="Um escudo azul do TypeScript marcado com TS"
/>

Você pode adotá-lo aos poucos: o TypeScript é compilado para JavaScript comum e funciona com todo o ecossistema JavaScript.

Este clipe público de flor é uma referência de vídeo de exemplo, e não uma gravação do curso de TypeScript.

## Comece por formas de dados úteis

Comece pelas partes da sua aplicação em que formas de dados claras são mais úteis.

```ts
const learnerName: string = 'Ada'
```

## Coloque os tipos para trabalhar

1. Escolha um tipo que corresponda aos dados, como `string` para texto.
2. Deixe o editor verificar se o valor é usado de modo consistente.
