# Um valor, algumas possibilidades

Dados reais nem sempre têm uma única forma. Um valor pode ser um número ou uma string,
ou pode estar presente ou ausente. Um tipo união descreve esse conjunto de
possibilidades.

```ts
type LessonId = string | number
```

`LessonId` aceita tanto uma string como `'welcome'` quanto um número como `1`.
O valor é de um membro por vez, e o TypeScript acompanha qual deles conforme seu
código é executado.

## Estreite com `typeof`

Antes de usar uma união, verifique qual membro você tem. O TypeScript chama isso de
estreitamento, e ele acontece automaticamente dentro de verificações comuns, como `typeof`.

```ts
function label(id: string | number): string {
  if (typeof id === 'number') {
    return `Lesson #${id}`
  }
  return id.toUpperCase()
}
```

Dentro do bloco `if` o valor é um `number`; depois dele, o TypeScript sabe que o
valor deve ser uma `string`. Assim, cada ramo é seguro sem nenhum cast.

## Estreite objetos por um campo em comum

As uniões também descrevem formas alternativas de objetos. Dê a cada membro um campo
literal em comum, geralmente chamado de discriminante, para que uma única verificação
selecione o ramo correto.

```ts
type Result = { status: 'ok'; value: number } | { status: 'error'; message: string }

function describe(result: Result): string {
  if (result.status === 'ok') {
    return `Value: ${result.value}`
  }
  return `Error: ${result.message}`
}
```

Verificar `result.status` já basta: no primeiro ramo existe apenas `value`,
e no segundo existe apenas `message`. O TypeScript rejeita qualquer tentativa de ler
o campo errado, o que detecta erros antes de o código ser executado.

## Mantenha as uniões precisas

1. Liste apenas as possibilidades que seus dados realmente têm.
2. Estreite a união antes de usar um campo ou método específico de um membro.
3. Trate todos os ramos, para que um novo membro apareça como um erro em vez de um
   bug silencioso.
