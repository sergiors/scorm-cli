# Describe an image's purpose

People who cannot see an image need its important information in text. Write alternative text that communicates the image's purpose in its context, not every visual detail.

- For an informative image, state the useful information it adds.
- For an image that is the only content in a link or button, describe the action or destination.
- For a purely decorative image, use an empty alternative (`alt=""`) so assistive technology can skip it.

Avoid repeating nearby text. The right alternative depends on why the image is there; there is no useful one-size-fits-all description.
