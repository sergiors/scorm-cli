# Make the outline meaningful

Use headings to organize a page into a clear outline. Start with a heading that describes the page, then use lower-level headings for sections and subsections. Do not choose a heading level just to get a particular visual size.

Use paragraphs for prose and real lists for related items. These structures help people scan the page and let assistive technology expose useful navigation.

Keep link text meaningful out of context. For example, “Read the keyboard guide” tells people more than “Click here.”
